# Extra practice: function notation

Nothing here is recorded. Take as many tries as you want, and the hints are free.

## Plug it in

```quiz
title: Plug it in
1. $f(x) = 5x + 2$. What is $f(3)$?
   = 17
2. $f(x) = 5x + 2$. What is $f(-4)$?
   = -18 | −18
3. $g(x) = x^2 - 6$. What is $g(-4)$?
   = 10
   > $(-4)^2 - 6 = 16 - 6$.
4. $h(x) = 2x^2 + x$. What is $h(-3)$?
   = 15
   > $2(9) + (-3) = 18 - 3$.
5. $r(x) = \sqrt{x + 7}$. What is $r(9)$?
   = 4
6. $c(n) = 15 + 2.5n$ is the cost in dollars of a pizza with $n$ toppings. What is $c(4)$?
   = 25
```

## Plug in or solve?

```quiz
title: Which question is it?
1. $f(x) = 4x - 7$. Find $f(2)$.
   = 1
2. $f(x) = 4x - 7$. Find $x$ when $f(x) = 2$.
   = 9/4 | 2.25
   > $4x - 7 = 2$, so $4x = 9$ and $x = \frac94$.
3. $f(x) = 4x - 7$. If $f(a) = 13$, what is $a$?
   = 5
   > $f(a) = 13$ means the output is 13, so solve $4a - 7 = 13$.
4. $f(x) = 4x - 7$. What is $f(0)$, and what does it tell you about the graph?
   - [x] $-7$: the graph crosses the y-axis at $(0, -7)$
   - [ ] $-7$: the graph crosses the x-axis at $(-7, 0)$
   - [ ] $\frac74$: the graph crosses the x-axis there
   > The input 0 gives the y-intercept.
```
