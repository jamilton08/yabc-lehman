# Extra practice: inequalities

Same calculator, but nothing here is recorded. Hints are free, and you can try as many times as you like. Use it to get fast before the assigned work, or to go back over something you missed.

## Read it and test it

```quiz
title: Warm-up

1. Which inequality says "$p$ is fewer than 30"?
   - [x] $p < 30$
   - [ ] $p \le 30$
   - [ ] $p > 30$
   > "Fewer than" doesn't include 30 itself, so the sign is $<$.

2. You must be **at least** 16 to work at the pool. Which inequality fits your age $a$?
   - [ ] $a > 16$
   - [x] $a \ge 16$
   - [ ] $a \le 16$
   > 16 counts, so the sign is $\ge$.

3. Is $x = 4$ a solution of $2x - 3 \le 5$?
   - [x] Yes
   - [ ] No
   > $2(4) - 3 = 5$, and $5 \le 5$ is true.

4. $-1 \ge x$ means the same as…
   - [x] $x \le -1$
   - [ ] $x \ge -1$
   - [ ] $x < -1$
   > Read it from $x$'s side: $x$ is less than or equal to $-1$.
```

## Same moves, no flip

```calc
title: No flip needed

1. x - 6 >= 2
2. 4x + 3 < 19
3. x/5 - 1 <= 2
4. 2x + 9 > -3
   > The answer x > −6 is negative, but you divided by 2, a positive. No flip.
5. 6x - 5 <= 4x + 7
```

## The flip

```calc
title: Keep or flip?

1. -5x < 30
2. -x + 2 >= 9
3. 8 - 3x > 20
4. -x/2 - 1 <= 3
5. -4(x - 1) < 16
   > Detaching the −4 (dividing by −4) flips it: x − 1 > −4, so x > −3.
```

## x on both sides

```calc
title: Both sides

1. 3x + 4 > x - 6
2. 2x - 1 <= 5x + 8
   > Move the 2x and you get −9 ≤ 3x, so −3 ≤ x, which means x ≥ −3.
3. 7 - 2x >= x + 1
4. 2(x + 3) < 4x - 2
```

## When x disappears

```calc
title: Every number, or no number?

1. 3x + 2 > 3x - 5
   > 2 > −5 is always true, so every number works.
2. 2(x + 1) <= 2x - 4
   > 2 ≤ −4 is never true, so no number works.
3. 5x - 4 >= 5(x - 1)
```

## Stories

```calc
title: From the story

1. 15 + 4t <= 55
   ? A gym charges a $15 sign-up fee plus $4 per class. You can spend at most $55. Let t = classes.
   > 4t ≤ 40, so t ≤ 10 classes.
2. 0.5m + 20 >= 32
   ? You have read 20 chapters so far and read half a chapter (0.5) every night. You need at least 32 chapters done by the deadline. Let m = nights.
   > 0.5m ≥ 12. Detaching 1/2 means multiplying by 2: m ≥ 24 nights.
3. 60 - 6d > 0
   ? A $60 phone card loses $6 a day. For how many days is there money left? Let d = days.
   > −6d > −60. Dividing by −6 flips it: d < 10.
```

```quiz
title: Write it yourself

1. A plumber charges \$45 to show up plus \$30 an hour. You can pay **no more than** \$180. Which inequality gives the hours $h$?
   - [x] $45 + 30h \le 180$
   - [ ] $30 + 45h \le 180$
   - [ ] $45 + 30h \ge 180$
   > The hourly rate multiplies $h$. "No more than" is $\le$. (It solves to $h \le 4.5$.)

2. Using that inequality, what is the greatest whole number of hours?
   = 4
   > $h \le 4.5$, so 4 full hours. Five hours would cost \$195.

3. A club needs **more than** 40 members to get a grant. It has 23 now and signs up 3 a week. How many full weeks $w$ until it qualifies? (Smallest whole number.)
   = 6
   > $23 + 3w > 40$, so $3w > 17$ and $w > 5.67$. Five weeks only gets to 38, so it takes **6**.
```
