# Practice set: linear equations

Twelve problems. Work each one on paper, then open the answer to check. Nothing here is recorded — it is for you.

## Two-step

1. $4x + 9 = 33$
2. $\dfrac{x}{5} - 3 = 4$
3. $-2x + 11 = 3$
4. $7 - 3x = -14$

<details><summary>Answers 1–4</summary>

1. $x = 6$ &nbsp; ($4x = 24$)
2. $x = 35$ &nbsp; ($\frac{x}{5} = 7$)
3. $x = 4$ &nbsp; ($-2x = -8$)
4. $x = 7$ &nbsp; ($-3x = -21$)

</details>

## Variables on both sides

5. $9x - 4 = 5x + 12$
6. $2x + 15 = 7x$
7. $6 - x = 2x - 9$
8. $\dfrac{1}{2}x + 3 = \dfrac{3}{2}x - 5$

<details><summary>Answers 5–8</summary>

5. $x = 4$
6. $x = 3$
7. $x = 5$
8. $x = 8$ &nbsp; (subtract $\frac{1}{2}x$: $3 = x - 5$)

</details>

## Parentheses and the weird cases

9. $2(x + 6) = 3x - 1$
10. $5(2x - 3) = 10x - 15$
11. $4(x + 1) = 4x + 9$
12. $-3(x - 2) + 4 = 2(1 - x)$

<details><summary>Answers 9–12</summary>

9. $x = 13$
10. All real numbers ($10x - 15 = 10x - 15$)
11. No solution ($4 = 9$ is false)
12. $x = 8$ &nbsp; ($-3x + 10 = 2 - 2x \Rightarrow 8 = x$)

</details>
